# Резервная копия сайта rida-art.ru

Снята **19.10.2026** (около 09:25–09:35 UTC) с работающего сайта. Подробности, находки и план переноса — в [REPORT.md](REPORT.md).

## Что где лежит

| Папка / файл | Содержимое |
|---|---|
| `html/` | 116 страниц из sitemap — **ровно так, как их отдаёт сервер** (`index.html` = главная, `product-xxxxxxx.html` = карточка товара). Исключение: `action.html` на живом сайте состоит из одних нулевых байтов (см. REPORT.md). |
| `assets/` | Всё, что страницы подгружают: **фото товаров и сайта** (`assets/cc3c1d0e-….selstorage.ru/<id товара>/…` и `assets/90f1661d-….selstorage.ru/site1060829/…` — логотипы, иконки, фоны), CSS и шрифты конструктора. Структура = `хост/путь` исходного URL. |
| `api/` | Сырые ответы `POST /api/v3/products/blocks` — остатки, цены, варианты (цвета/виды) товаров. |
| `data/products.json`, `data/products.csv` | **92 товара**: название, цена, старая цена, описание, остаток, варианты, каталоги, список фото (основной файл + превью). CSV — в UTF-8 с BOM, разделитель `;`, открывается в Excel. |
| `data/catalogs.json` | 14 каталожных блоков: какие товары в каком каталоге и в каком порядке, сортировка. |
| `data/pages.json` | Все страницы: `title`, meta-теги, заголовки, **тексты**, очищенный HTML блоков, картинки, ссылки. |
| `data/site.json` | Меню, подвал, контакты, координаты карты, иконки, логотипы, код Яндекс.Метрики, конфиг конструктора. |
| `data/external_links.json` | Внешние ссылки по страницам. |
| `meta/` | `robots.txt`, `sitemap.xml`, страница 404, заголовки ответа главной, DNS (`dns.json`), редиректы и TLS-сертификат. |
| `verify.json` | Результат проверки полноты (что скачано, что сломано на самом сайте). |
| `MANIFEST.csv` | Список всех файлов с исходным URL, размером и SHA-256. |
| `import-woocommerce/` | **Готовый пакет импорта в WordPress + WooCommerce**; начинать с `import-woocommerce/README.md`. |
| `scripts/backup.py` | Скрипт, которым сделана копия. Повторный запуск (см. ниже) обновит копию. |
| `scripts/build_woocommerce_import.py`, `scripts/validate_import.py` | Сборка и проверка пакета импорта (`python -I -X utf8 ...`). |

## Как обновить копию

Скрипт использует только стандартную библиотеку Python. Из любой папки:

```bash
python -I C:\l1bot\rida-art.ru-backup\scripts\backup.py --refresh
```

Без `--refresh` уже скачанные файлы берутся из кеша, а пересобираются только `data/`, `verify.json` и `MANIFEST.csv`.

## Как использовать при переносе

* Товары для импорта — `data/products.json` (полные данные) или `data/products.csv` (плоская таблица). Путь к каждому фото — в поле `images[].file` (JSON) / `images_local` (CSV) относительно этой папки.
* У каждого фото два файла: основной (с карточки товара, `images[].file`) и уменьшенное превью для каталога (`images[].thumbnails[]`). Для нового сайта нужны основные.
* Тексты страниц — `data/pages.json` → `pages[].sections[].text` (чистый текст) и `.html` (разметка без классов конструктора).
* Оригинальный HTML остаётся в `html/` как эталон внешнего вида; CSS и шрифты — в `assets/…selcdn.net/` и `assets/fonts.*`.
