# Пакет переноса rida-art.ru → WordPress + WooCommerce

Собран из резервной копии от 19.10.2026 скриптами `scripts/build_woocommerce_import.py` (сборка) и `scripts/validate_import.py` (проверка: файлы заново прочитаны с диска и сверены с копией — ошибок нет).

> **Важно:** прогнать импорт в настоящем WooCommerce и запустить `install_on_server.sh` на вашем сервере я не мог (нет доступа к серверу и нет PHP на этом компьютере). Структура файлов проверена программно и сделана по формату стандартного импортёра WooCommerce, но первый запуск — это и есть проверка. Если что-то пойдёт не так, пришлите текст ошибки.

## Что внутри

| Файл | Для чего |
|---|---|
| `install_on_server.sh` | Скрипт для сервера: ставит WordPress (ru_RU), WooCommerce, Cyr-To-Lat, настраивает рубли и адреса, создаёт категории, загружает страницы и картинки |
| `products_import.csv` | **Товары для импорта** (82 простых + 7 вариативных + 24 вариации = 113 строк). Картинки подтягиваются со старого сайта |
| `products_import_local-images.csv` | То же, но картинки берутся с вашего сервера (запасной вариант, если старый сайт уже отключён) |
| `categories.csv`, `create_categories.sh` | 15 категорий с нужными адресами (slug) и вложенностью; скрипт создаёт их командами WP-CLI |
| `pages_import.xml` | 7 страниц для «Инструменты → Импорт → WordPress»: О нас, Корпоративные подарки, Доставка и оплата, Оферта, Политика конфиденциальности, Контакты, Главная (черновик) |
| `uploads/rida-import/` | 180 фото товаров (`products/<артикул>-<номер>.jpeg`) и 7 картинок страниц (`pages/`) |
| `redirects.csv` | Старые адреса → новые (для 301-редиректов после запуска) |
| `review.csv` | **Что проверить вручную** — 36 пунктов (см. ниже) |

## Быстрый путь: три команды

Выполняются в PowerShell на этом компьютере. Пароль SSH вы вводите сами.

1. Скопировать пакет на сервер:

```bash
scp -r C:\l1bot\rida-art.ru-backup\import-woocommerce u0965861@37.140.192.134:~/
```

2. Зайти на сервер:

```bash
ssh u0965861@37.140.192.134
```

3. Запустить установку (на сервере):

```bash
bash ~/import-woocommerce/install_on_server.sh
```

Скрипт показывает, что делает, и спросит: пароль базы `u0965861_ridawp`, логин, e-mail и пароль администратора будущего сайта (придумайте новые, не от хостинга). Папка сайта по умолчанию `~/rida-art`; если у вас другая — задайте путь:

```bash
TARGET_DIR=/полный/путь/к/папке/сайта bash ~/import-woocommerce/install_on_server.sh
```

Скрипт не стирает существующие файлы: если папка не пуста, он покажет список и попросит ввести `yes`. На уже установленный WordPress он не встанет.

## Как открыть новый сайт, пока DNS не переключён

Домен `rida-art.ru` пока ведёт на старый сайт (`85.119.149.37`), и посетители видят его. Чтобы смотреть новый сайт только у себя, на своём компьютере (от имени администратора) добавьте строку в файл `C:\Windows\System32\drivers\etc\hosts`:

```
37.140.192.134 rida-art.ru
```

После этого `http://rida-art.ru/wp-admin/` откроет новый сайт — только на этом компьютере. **Когда сайт запущен, эту строку удалите.** Для HTTPS выпустите сертификат в панели хостинга уже после переключения DNS и затем замените адрес сайта на `https://` (Настройки → Общие).

## Импорт товаров (в админке)

1. **Товары → Импорт** → выбрать `products_import.csv` → «Продолжить».
2. Поле «Обновить существующие товары» оставьте выключенным. Столбцы должны сопоставиться сами; если какой-то нет — выберите вручную по таблице ниже.
3. «Запустить импорт». WooCommerce сам скачает 180 фото и положит их в «Медиафайлы» (импорт идёт порциями, окно закрывать нельзя).
4. **Делайте импорт, пока старый сайт работает** — фото берутся с его хранилища. Если старый сайт уже отключён, скопируйте `uploads/rida-import` (это делает `install_on_server.sh`) и импортируйте `products_import_local-images.csv`; в нём адреса фото вида `https://rida-art.ru/wp-content/uploads/rida-import/products/<артикул>-<номер>.jpeg`. Сервер должен сам открывать эти адреса, поэтому такой вариант работает **только после переключения DNS домена на новый сервер**. Если нужен другой адрес — пересоберите пакет: `python -I -X utf8 scripts\build_woocommerce_import.py --site-url https://ваш-адрес`.

### Как поля старого сайта легли в WooCommerce

| Конструктор | WooCommerce |
|---|---|
| id товара (`/product-xxxxxxx`) | **Артикул (SKU)**; старый адрес сохранён в поле `_rida_old_url` |
| название | Название |
| «краткое описание» (его показывал сайт) | Краткое описание |
| «полное описание» (на сайте не показывалось) | Описание — только если там есть новый текст, например «Высота 17 см» |
| цена, старая цена | Цена и «Цена распродажи» (у «Ангела цветочного в домике»: 3800 → 3000) |
| остаток | Количество; пусто = остаток не ведётся; 0 = «нет в наличии» |
| варианты (7 товаров, 24 варианта) | Вариативный товар; атрибут «Цвет» или «Вариант» |
| фото (первое — главное) | Изображения |
| каталог (страница) | Категории; подборки `/page97–101` стали подкатегориями «Весенней и пасхальной коллекции» |

Категории после импорта: Новинки 10, Ангелы 25, Домики 8, Маяки 4, Птицы 11, Лошадки 5, Грибы 8, Наборы 6, пасхальные подборки 8 + 5 + 4 + 6 + 12; «Новогодние подарки» создана пустой (на старом сайте там тоже пусто).

## Что решено за вас (можно поменять)

* **Не импортированы 3 тестовых товара** (`isqjygk` «Товар», `ktdaykn` «Товар 2», `tdjolkd` «Лошадка»): цена 1 ₽, без фото и описания.
* **3 товара импортируются как черновики** (`jllanvr`, `qdnepiz`, `ypnqirn`): на старом сайте они открывались только по прямой ссылке и не входили в каталоги. Решите, в какую категорию их положить, и опубликуйте.
* **Заглушки «Краткое описание товара» не импортированы** (3 товара). Дубли названий («Домик ваза» ×5, «Набор грибов» ×3 …) оставлены отдельными товарами — список в `review.csv`.
* **Сайт закрыт от поисковиков** (Настройки → Чтение), пока вы не решите запускать.
* Названия атрибутов выровнены: параметры «Ангел», «ангел пухляш», «уютохранитель» — это цвета, они названы «Цвет».

## Что нужно доделать вручную

1. **Оферта и политика конфиденциальности — незаполненные шаблоны** («(наименование организации)», «Название организации, ИП:» …). Заполните реквизиты продавца до публикации. Реквизиты юрлица на старой странице «Контакты»: ООО «Мультивест», ИНН 9716001940 — проверьте актуальность.
2. **Часы работы расходятся:** на главной «Пн—Пт 10:00—18:00», на «Контактах» «10:00—19:00».
3. **Страницы «Обмен и возврат» на старом сайте не было** (ссылка в подвале вела на 404) — создайте.
4. **Главная** — только заготовка-черновик (текст «О мастерской» и контакты). Оформление зависит от темы. После оформления: Настройки → Чтение → «Статическая страница».
5. **Меню** (как на старом сайте): Главная · Новинки · Весенняя коллекция · Ангелы · Домики · Маяки · Птицы · Лошадки · Грибы · Контакты · Доставка. Внешний вид → Меню.
6. **Не перенесено:** вес и габариты товаров (нужны для расчёта доставки), заказы и клиенты (нужно выгрузить из старого кабинета), порядок товаров вручную внутри категорий, SEO-заголовки и описания (на старом сайте это были заглушки «Товар»), оплата и доставка (подключаются плагинами: ЮKassa/Т‑Банк, СДЭК/Boxberry/Почта России).
7. **65 товаров без описания** — перечислены в `review.csv`; описания важны для поиска.
8. **Редиректы со старых адресов** (`redirects.csv`): `/product-<артикул>` → страница товара с этим артикулом, `/angels` → `/product-category/angels/` и т. д. Когда сайт заработает, я могу сделать для этого небольшой плагин и проверить на реальном сайте.
9. **Яндекс.Метрика:** счётчик `103283050` оставьте тот же, код — в `data/site.json`. Для вставки кода подойдёт плагин «WPCode».

## Безопасность

Пароли от SSH и базы вы публиковали в переписке — **смените их** (панель хостинга) после установки. Скрипт не сохраняет пароли, кроме `wp-config.php` (там пароль базы нужен самому WordPress; права `640`). После установки удалите с сервера папку `~/import-woocommerce`, когда убедитесь, что всё импортировано.
