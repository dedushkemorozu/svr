# Резервная копия сайта svr-mos.ru (ООО «СВР»)

Снята **20.10.2026** (≈14:17 UTC) с работающего сайта. Находки и план переноса — в [REPORT.md](REPORT.md).

Сохранены **два сайта**:

1. **svr-mos.ru** — действующий, собран в конструкторе (тот же, что был у rida-art.ru: Selectel / tb.ru).
2. **www.svr-mos.ru** — старый самописный HTML-сайт на хостинге Beget. Он до сих пор открывается по адресу с `www`, на нём есть материалы, которых нет на новом (фото объектов в высоком разрешении, PDF с реквизитами, схема проезда).

## Что где лежит

| Папка / файл | Содержимое |
|---|---|
| `html/` | 11 страниц из sitemap, **ровно так, как их отдаёт сервер** (`index.html` = главная). |
| `assets/` | Всё, что подгружают страницы: **фото** (`assets/90f1661d-….selstorage.ru/site1160494/…`), **декларация о соответствии** `…/site1160494/EAC.pdf`, CSS и шрифты конструктора. Структура: `хост/путь` исходного URL. |
| `data/pages.json` | Все страницы: `title`, meta-теги, заголовки, **тексты**, очищенный HTML блоков, картинки, ссылки. |
| `data/site.json` | Меню, иконки, логотип, конфиг конструктора (в т. ч. ключ Яндекс.Карт). |
| `data/external_links.json` | Внешние ссылки по страницам. |
| `www-old/` | Старый сайт с www целиком: HTML, CSS, фото (`Content/…`, часть в `.tif`), `OOO SVR.pdf` (реквизиты). Журнал обхода — `www-old/_crawl.json`. |
| `meta/` | `robots.txt`, `sitemap.xml`, страница 404, заголовки ответа главной, DNS (`dns.json`), редиректы и TLS-сертификат. |
| `verify.json` | Проверка полноты. |
| `MANIFEST.csv` | Список всех файлов с исходным URL, размером и SHA-256. |
| `scripts/backup.py` | Копия основного сайта (адаптирована из скрипта rida-art.ru). |
| `scripts/backup_www_old.py` | Копия старого сайта с www. |

`data/products.*` и `data/catalogs.json` пустые (0 записей): магазина и каталога товаров на сайте нет. Файлы остались от общего скрипта.

## Как обновить копию

Нужна только стандартная библиотека Python:

```bash
python -I -X utf8 C:\l1bot\svr-mos.ru-backup\scripts\backup.py --refresh
```

```bash
python -I -X utf8 C:\l1bot\svr-mos.ru-backup\scripts\backup_www_old.py
```

Без `--refresh` уже скачанные файлы берутся из кеша, пересобираются только `data/`, `verify.json` и `MANIFEST.csv`.
