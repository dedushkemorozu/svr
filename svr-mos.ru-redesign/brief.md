## Заказчик

изыскания, обследование, отбор проб и лабораторные испытания, технологические решения, проектная и рабочая

снабженцы промышленных предприятий, генподрядчики, муниципальные заказчики.

## Задача заказчика (дословно)
«Представь, что ты веб-дизайнер экстра мирового класса и тебе надо выполнить заказ на редизайн этого сайта.
Тематика — очистка воды на промышленных объектах, так что общий цветовой фон должен быть тёмно-синим и голубым.
Сделай сайт, который можно всем показывать в пример и занимать первое место.»

=> Тёмная тема: основной фон тёмно-синий (navy), акценты голубые/циан. Уровень Awwwards/CSS Design Awards,
но для серьёзного промышленного B2B: доверие, инженерная точность, читаемость. Без «киберпанка» и кислотности.

## Платформа и ограничения (ВАЖНО)
- WordPress 7.1.3, блочная тема Twenty Twenty-Five (TT5), сайт https://svr-mos.ru, ЧПУ включены.
- Свои файлы темы загрузить НЕЛЬЗЯ. Менять можно только:
  1. Global styles (theme.json-объект): settings (палитра, шрифты, размеры, layout) + styles (элементы, блоки)
     + `styles.css` — произвольный CSS сайта. Пишется POST /wp/v2/global-styles/6 c {settings, styles}.
  2. Части шаблона (header, footer) и шаблоны (page, page-no-title, 404, index и т.д.) — блочная разметка,
     POST /wp/v2/template-parts/twentytwentyfive//header и /wp/v2/templates/twentytwentyfive//page.
  3. Контент страниц — блочная разметка Gutenberg (core-блоки). Пользователь — администратор с unfiltered_html,
     поэтому можно core/html с инлайн-SVG и даже <style> внутри него (но лучше CSS держать в global styles).
- Шрифты: в TT5 встроены Manrope (variable 200–800, есть кириллица) — slug `manrope`; также Fira Code
  (`fira-code`, моно, кириллица) и др. Сторонние шрифты не подключать (Google Fonts в РФ — риск, плюс GDPR/152-ФЗ).
- JS нет (кроме того, что даёт WordPress: Interactivity API у navigation — мобильное меню-оверлей работает).
  Анимации — только CSS (prefers-reduced-motion обязательно уважать).
- Плагинов дизайна нет (Yoast SEO установлен, но не трогаем).
- Разметка блоков должна быть валидной для редактора: JSON в комментарии блока должен соответствовать HTML
  (классы has-*-color, has-background, style="..." и т.д. — так, как их сохранил бы Gutenberg). Безопаснее
  простые блоки: group, columns/column, heading, paragraph, list/list-item, image, gallery, buttons/button,
  cover, separator, spacer, html. Свои классы — через атрибут "className" (тогда класс и в HTML).

## Требования качества
- Тёмно-синий фон по всему сайту, голубые акценты; контраст текста WCAG AA (≥4.5:1 для обычного текста).
- Mobile-first: идеально на 360–430 px, без горизонтального скролла; на десктопе 1440 px — эффектно.
- Чёткая иерархия, мощный первый экран, очевидные CTA (позвонить / написать), блок «как мы работаем»
  (этапы полного цикла — из фактов), продукция, объекты (кейсы), документы/доверие, контакты.
- Семантика: один h1 на страницу; логичная иерархия заголовков; alt у изображений; фокус-стили видимы.
- Производительность: без тяжёлых эффектов, анимации только transform/opacity, prefers-reduced-motion.

## Справка по теме TT5 (базовый theme.json темы)
- useRootPaddingAwareAlignments: true; layout по умолчанию contentSize 645px, wideSize 1340px (переопределяемо в global styles).
- Пресеты отступов (slug → size): 20=10px, 30=20px, 40=30px, 50=clamp(30px,5vw,50px), 60=clamp(30px,7vw,70px),
  70=clamp(50px,7vw,90px), 80=clamp(70px,10vw,140px). Использование: "var:preset|spacing|50" → var(--wp--preset--spacing--50).
- Размеры шрифта (slug): small 0.875rem, medium 1–1.125rem (fluid), large 1.125–1.375rem, x-large 1.75–2rem, xx-large 2.15–3rem.
  Можно задать свои в settings.typography.fontSizes.theme (полностью заменит список темы).
- Шрифты: manrope ("Manrope, sans-serif", 200–800), fira-code ("\"Fira Code\", monospace", 300–700). Оба с кириллицей.
- Палитра: slugs base, contrast, accent-1 … accent-6 (переопределяемо в settings.color.palette.theme; можно добавить свои slugs).
- Блок core/image поддерживает lightbox: {"lightbox":{"enabled":true}} (увеличение по клику, работает на фронтенде).
- Шаблоны темы: index, home, front-page? (нет), page, page-no-title, single, archive, search, 404 и др.; части шаблона header, footer
  (+ варианты vertical-header, header-large-title, footer-columns, footer-newsletter, sidebar).
- Текущее состояние сайта: уже применены глобальные стили (светлая палитра, Manrope) и простые header/footer/страницы — всё это
  будет ЗАМЕНЕНО редизайном целиком.
