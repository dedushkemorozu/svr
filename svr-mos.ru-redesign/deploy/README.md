# Пакет публикации редизайна svr-mos.ru («Чертёж»)

WordPress 7.1.3 · тема Twenty Twenty-Five · всё применяется через REST API под администратором (`unfiltered_html`).
Файлы темы не меняются. Шаги и их порядок описаны в `manifest.json`, ниже то же самое для человека.

## Что внутри

| Файл | Назначение | Маршрут |
|---|---|---|
| `global-styles.json` | палитра, шрифты, размеры, layout, стили элементов и блоков + `styles.css` в `styles.css` | `POST /wp/v2/global-styles/6` (тело — файл целиком) |
| `parts/header.html`, `parts/footer.html` | шапка и подвал | `POST /wp/v2/template-parts/twentytwentyfive//header` · `…//footer`, тело `{"content": …}` |
| `templates/page.html`, `templates/page-no-title.html`, `templates/404.html` | шаблоны темы (есть в TT5) | `POST /wp/v2/templates/twentytwentyfive//<slug>`, тело `{"content": …}` |
| `templates/wp-custom-template-obekt.html` | новый шаблон «Страница объекта» (крошки «Главная / Наши объекты / …») | `POST /wp/v2/templates` с `{"slug":"wp-custom-template-obekt","title":"Страница объекта","content": …}`; если уже создан — `POST /wp/v2/templates/twentytwentyfive//wp-custom-template-obekt` с `{"content": …}` |
| — | alt логотипа (id 7): «ООО «СВР» — на главную» | `POST /wp/v2/media/7` `{"alt_text": "ООО «СВР» — на главную"}` |
| `templates/wp-custom-template-produkciya.html` | новый шаблон «Страница продукции» (крошки «Главная / Продукция / …», «Продукция» → https://svr-mos.ru/prod/) | `POST /wp/v2/templates` с `{"slug":"wp-custom-template-produkciya","title":"Страница продукции","content": …}`; если уже создан — `POST /wp/v2/templates/twentytwentyfive//wp-custom-template-produkciya` с `{"content": …}` |
| `pages/prod-<slug>.html` (5 файлов) | НОВЫЕ страницы продукции, дочерние «Нашей продукции» (id 55) | `POST /wp/v2/pages` `{"title": …, "slug": …, "parent": 55, "status": "publish", "comment_status": "closed", "template": "wp-custom-template-produkciya", "content": …}`; если страница с таким адресом уже есть — `POST /wp/v2/pages/<id>` |
| `pages/49.html` … `pages/58.html` | контент страниц | `POST /wp/v2/pages/<id>` `{"content": …, "template": …}` |

Страницы продукции (адрес → заголовок → фото медиатеки): `/prod/stanciya-dozirovaniya/` «Станции дозирования и приготовления реагентов двухкамерные» (id 13);
`/prod/reaktor-trehkamernyj/` «Реактор трёхкамерный» (14); `/prod/reaktor-odnokamernyj/` «Реактор однокамерный» (15);
`/prod/ustanovka-obezzarazhivaniya/` «Установка комплексного обеззараживания сточных вод» (16); `/prod/kns/` «Канализационные насосные станции» (17).
В разметке страниц используются только URL и id картинок медиатеки — id самих страниц продукции нигде не прописаны, на сайте они появятся при создании.

Шаблоны страниц: 49 — `page-no-title`; 51–54 — `wp-custom-template-obekt`; 50, 55–58 — `""` (шаблон по умолчанию `page`).
Заголовки и адреса страниц не меняются. В `manifest.json` у каждого файла есть контрольная сумма (`sha256_16` — первые
16 знаков SHA-256), по ней можно проверить, что файл не изменился по пути.

## Порядок применения

0. **Резервная копия текущего состояния** (для отката): `GET /wp/v2/global-styles/6?context=edit`,
   `GET /wp/v2/template-parts/twentytwentyfive//header?context=edit` (и `footer`),
   `GET /wp/v2/templates/twentytwentyfive//page?context=edit` (и `page-no-title`, `404`),
   `GET /wp/v2/pages/<id>?context=edit` для 49–58, `GET /wp/v2/media/7?context=edit`. Сохранить ответы.
   Убедиться, что пост глобальных стилей — 6: `GET /wp/v2/themes?status=active`, ссылка `wp:user-global-styles`.
1. Global styles: тело — содержимое `global-styles.json` как есть.
2. Части шаблона: header, footer (менялись только если `cmp` с предыдущей публикацией показывает отличие).
3. Шаблоны: page, page-no-title, 404.
4. Шаблоны `wp-custom-template-obekt` и НОВЫЙ `wp-custom-template-produkciya` (должны существовать до шагов 6–7, иначе WP не примет `template`).
5. Alt логотипа.
6. СОЗДАТЬ 5 страниц продукции (`POST /wp/v2/pages`, parent 55, publish, comment_status closed, шаблон продукции). Записать id из ответа,
   проверить, что `link` каждой = `https://svr-mos.ru/prod/<slug>/`.
7. Страницы 55 и 49 (ссылки на страницы продукции уже работают), затем остальные 50–54, 56–58 в порядке манифеста.
8. Сбросить кэш страниц, если на хостинге есть кэш или CDN.

Откат: отправить сохранённые на шаге 0 тела теми же `POST`. Пользовательский шаблон удаляется так:
`DELETE /wp/v2/templates/twentytwentyfive//wp-custom-template-obekt?force=true`. Перед этим страницам 51–54 нужно
вернуть `"template": ""`.

## Что проверить после публикации на сайте

1. Открыть https://svr-mos.ru/ и каждую страницу из меню на телефоне и на компьютере. Пройти по 4 страницам объектов.
   Открыть несуществующий адрес: должен показаться шаблон 404 с кнопками.
2. В админке открыть каждую страницу 49–58 в редакторе: не должно быть сообщения «Блок содержит непредвиденное или
   недопустимое содержимое». В редакторе сайта открыть шапку, подвал и шаблоны page, page-no-title, 404,
   «Страница объекта».
3. Мобильное меню: открывается, закрывается крестиком и клавишей Esc. Кнопки «Позвонить» открывают звонок, «Написать»
   открывает почту.
4. /prod/: при клике по рендеру открывается lightbox. /docs/: «Открыть PDF» открывает PDF в новой вкладке, «Скачать PDF»
   скачивает файл.
5. Шаблоны TT5, которые мы не меняли (index, search, archive, single), перекрашены токенами. Записей на сайте нет,
   но их стоит открыть и посмотреть.
6. Yoast SEO не трогали. Заголовки и адреса страниц остались прежними.

### Как добавить технические параметры на страницу продукции

Когда владелец пришлёт параметры, на странице продукции (в админке → Страницы → «Наша продукция» → нужная → редактор) заменить блок-заглушку «Технические параметры — по запросу…» (группа
`svr-spec-note`) на таблицу характеристик `svr-spec`: блок «Таблица» с классом `svr-spec` (Дополнительные CSS-классы), две колонки, шапка «Параметр / Значение», в первой колонке названия параметров, во второй значения
с единицами измерения; заметка — подпись таблицы. Готовая разметка — `system/components.md`, фрагмент 19 (шаблон с условными подписями; свои цифры подставляет только заказчик). Перед таблицей оставить H2
«Технические параметры»; кнопки «Позвонить/Написать» можно оставить ниже. Через REST: `POST /wp/v2/pages/<id>` с новым `content` (тот же файл `pages/prod-<slug>.html`, где группа `svr-spec-note` заменена
таблицей). Стили таблицы уже есть в `styles.css` — публиковать ничего, кроме содержимого страницы, не нужно.
